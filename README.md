# Розумний план-конспект — пакет для розгортання

Це вебзастосунок/PWA для створення адаптованих планів-конспектів уроків для учнів з легкими інтелектуальними порушеннями.

## У програмі
- Вводите предмет, клас і тему.
- Обираєте тривалість і тип уроку.
- Генерується повний конспект із корекційно-розвитковою спрямованістю.
- Текст можна редагувати, зберігати, повторно відкривати з історії браузера.
- Є експорт у Word-сумісний DOC, друк і PDF.
- PWA-режим для встановлення на Android та комп'ютері після розміщення на HTTPS.

## Найпростіший шлях — опублікувати через Render

Для публікації потрібні власні акаунти GitHub і Render, а також OpenAI API key. Я не можу створити акаунти або підтвердити дії замість вас, тому що це потребує вашого входу та дозволу. Не надсилайте мені пароль чи API-ключ.

1. Завантажте цей ZIP і розпакуйте його.
2. Створіть репозиторій на GitHub та завантажте в нього вміст папки (не сам ZIP). Не додавайте API-ключ у файли.
3. Увійдіть у Render і виберіть створення нового Blueprint, під'єднайте ваш GitHub-репозиторій. Render прочитає `render.yaml`.
4. Під час створення сервісу Render попросить значення `OPENAI_API_KEY`. Вставте його безпосередньо у захищене поле Render. Не вставляйте ключ у браузерний код, GitHub або повідомлення.
5. Після успішного розгортання Render надасть HTTPS-адресу виду `https://...onrender.com`.
6. Відкрийте цю адресу на Android у Chrome → меню ⋮ → «Установити додаток» або «Додати на головний екран».
7. Для встановлення на комп'ютер відкрийте ту саму адресу у Chrome/Edge та виберіть значок встановлення або відповідний пункт меню.

Пояснення Render Blueprint: https://render.com/docs/blueprint-spec
Створення API key та перший запит: https://developers.openai.com/api/docs/quickstart

## Локальний запуск на Windows
1. Встановіть Node.js 18 або новіший: https://nodejs.org/
2. Відкрийте PowerShell у папці програми.
3. Введіть (підставте власний ключ):
   `$env:OPENAI_API_KEY="ВАШ_API_КЛЮЧ"`
4. Запустіть: `node server.js`
5. Відкрийте `http://localhost:3000`.

## Витрати та безпека
- API оплачується окремо від підписки ChatGPT. Витрати залежать від кількості й обсягу запитів; можна встановити ліміти бюджету у кабінеті API.
- API-ключ зберігається тільки як змінна середовища сервера.
- Сервер відправляє `store:false` у запиті Responses API.
- Історія конспектів зберігається лише локально в браузері пристрою, не синхронізується автоматично.
- Не вносьте персональні дані, ПІБ, діагнози чи іншу конфіденційну інформацію дітей.
- Перед використанням перевіряйте кожен конспект на відповідність навчальній програмі, можливостям учнів і правилам безпеки.

## Модель
За замовчуванням використовується `gpt-6-astra` відповідно до актуального прикладу в офіційному OpenAI API Quickstart. Якщо ця модель недоступна у вашому API-проєкті, у Render змініть `OPENAI_MODEL` на модель, доступну вашому акаунту.
